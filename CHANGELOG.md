## [1.1.0] - 2026-11-11

### Added

- Sessions continue while the app is closed: the session is saved to the SD card, and on reopening the time spent away is deducted from the remaining time, moving through any phases that ended meanwhile. Paused sessions stay paused.
- README disclaimer that the code was generated by AI.

### Changed

- Back during a session now leaves the app with the session still running; hold Back to stop the session and return to the mode menu.
- Timing uses the real-time clock instead of the system tick counter.

## [1.0.0] - 2026-11-11

### Added

- Pomodoro timer app for Flipper Zero, driven by a finite state machine.
- Session mode menu: Short (25 min focus / 5 min rest) and Long (50 min focus / 10 min rest).
- Long break after every fourth focus interval: 15 min in Short mode, 30 min in Long mode.
- Pause/resume (OK), skip to next phase (Right) and return to menu (Back) during a session.
- Countdown display with progress dots for the current cycle.
- Vibration, sound and backlight alerts when focus or a break begins.
- README and MIT license.
