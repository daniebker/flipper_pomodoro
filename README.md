# Pomodoro for Flipper Zero

A simple Pomodoro timer for the Flipper Zero. Pick a session length, then work in focus intervals separated by short breaks, with a longer break after every fourth focus interval.

> [!NOTE]
> **AI-generated code:** the source code in this project was generated by an AI assistant (Claude, by Anthropic). Review it before relying on it, and use it at your own risk; it is provided as-is under the [MIT License](LICENSE), without warranty of any kind.

## Session modes

| Mode  | Focus  | Short break | Long break (after 4 focus intervals) |
|-------|--------|-------------|--------------------------------------|
| Short | 25 min | 5 min       | 15 min                               |
| Long  | 50 min | 10 min      | 30 min                               |

Phases never start on their own. When a phase ends, the screen lights up, the Flipper vibrates and beeps (two short beeps when focus is up next, one longer tone when a break is), and the timer shows **Up next:** with the next phase's full time. Press OK to start it when you're ready.

## Controls

**Mode menu**

| Button      | Action             |
|-------------|--------------------|
| Up / Down   | Choose Short or Long |
| OK          | Start the session  |
| Left        | Open the stats page |
| Back        | Exit the app       |

**Timer**

| Button | Action                                  |
|--------|-----------------------------------------|
| OK     | Pause / resume, or start the phase that's up next |
| Right  | Skip to the next phase (counts as done); it waits for OK |
| Left   | Open the stats page (the timer keeps running) |
| Back   | Open the leave menu (see below)         |
| Hold Back | Stop the session and return to the mode menu |

The four dots under the countdown show how many focus intervals you have finished in the current cycle.

## Stats

Press Left on the menu or timer to see your stats; press Left, OK or Back to close them.

| Row           | Meaning |
|---------------|---------|
| Total         | Lifetime focus time, and (in brackets) pomodoros completed |
| Today         | Focus time and pomodoros completed today |
| Daily average | Lifetime focus time divided by the days since your first session, including days with no focus |
| Best day      | Most focus time in a single day |
| Streak        | Consecutive days with at least one completed pomodoro, and your longest streak |

- **Focus time** counts every minute actually spent focusing, including focus intervals you skip or stop part-way; time spent paused doesn't count.
- **Pomodoros completed** only counts focus intervals that ran to the end. (Skipped ones still count toward the four before a long break.)
- Focus intervals that finish while the app is closed are counted when you reopen it.
- Days follow the Flipper's clock and change at local midnight. An interval that crosses midnight counts toward the day it ended.
- A streak stays alive until a whole day passes with no completed pomodoro.
- Stats are saved to `apps_data/pomodoro_app/stats.bin` on the SD card. Delete that file to reset them.

## Leaving and reopening the app

Pressing Back during a session opens a menu:

- **Continue tracking:** close the app and keep the session running in the background (selected by default).
- **Stop tracking & exit:** end the session and close the app. Any focus time so far is added to your stats.
- Press **Back** again to return to the timer.

If you choose Continue tracking, you can use other apps. When you reopen Pomodoro, the time you were away is deducted from the remaining time, so the countdown shows where the session really is. If the current phase ended while you were away, it's counted as usual and the next phase is waiting for you to start it.

- A **paused** session stays paused while the app is closed and loses no time.
- The session is saved to `apps_data/pomodoro_app/session.bin` on the SD card and survives a restart.
- The Flipper can only run one app at a time, so there are no alerts while the app is closed, and the countdown isn't shown on the home screen.

## Building

Requires [uFBT](https://github.com/flipperdevices/flipperzero-ufbt).

```sh
ufbt            # build dist/pomodoro_app.fap
ufbt launch     # build, install and run on a connected Flipper
```

The app appears under **Apps → Tools → Pomodoro**.

### Faster testing

In `pomodoro_fsm.c`, set `POMODORO_SECONDS_PER_MINUTE` to `1` so every "minute" lasts one second. Set it back to `60` before real use.

## How it works

The app is driven by a finite state machine in `pomodoro_fsm.c`. All transitions happen in `pomodoro_dispatch()`; `pomodoro_app.c` only turns button presses into events, draws the current state and plays alerts.

```
Select ──OK──▶ Focus ──done──▶ Ready ──OK──▶ Short break ──done──▶ Ready ──OK──▶ Focus …
                 │
                 └─4th done──▶ Ready ──OK──▶ Long break ──done──▶ Ready ──OK──▶ Focus (cycle resets)

Any timed phase ──OK──▶ Paused ──OK──▶ same phase
Any timed phase / Paused / Ready ──hold Back──▶ Select ──Back──▶ Exit
```

Durations live in the `pomodoro_modes` table in `pomodoro_fsm.c` if you want to change them.
